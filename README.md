# 三指复制粘贴（ThreeSwipeCopy）

一个极简的 macOS 菜单栏小工具，实现类似 BetterTouchTool 的日常高频操作，手势可以**自定义绑定动作**：

- **三指上滑 = 复制（⌘C）**（默认，可改）
- **三指下滑 = 粘贴（⌘V）**（默认，可改）
- **三指按住不动 + 第四指点按一下 = 删除到废纸篓（⌘⌫）**（默认，可改）

此外还内置了更多可选手势（默认「无动作」，需要时在菜单里绑定，避免与系统手势冲突）：

| 手势 | 说明 |
| --- | --- |
| 两指轻点 / 两指左滑 / 两指右滑 | 轻点、左右快速甩动（纵向留给系统滚动） |
| 四指上滑 / 下滑 / 左滑 / 右滑 | 四指方向滑动 |
| 四指轻点 | 四指同时落下并抬起 |

选中任何文字 / 文件 / 元素后直接触发，无需额外操作。所有手势都能在菜单里换成你想要的
快捷键、App 或系统动作。

## 工作原理

- 使用 Apple 私有框架 **MultitouchSupport**（BetterTouchTool / Jitouch 同款底层方案）
  读取触控板原始触点：
  - 跟踪三指位移识别「三指上滑 / 下滑 / 左滑 / 右滑」四个方向
  - 独立跟踪「三指按住 + 第四指点按」，与滑动手势互不干扰
  - 另外识别「两指轻点 / 两指左右快速甩动 / 四指滑动 / 四指轻点」，
    每个都带独立的防误触状态机（位移阈值、时间窗口、冷却）
- 为什么不走 `CGEventTap`：macOS 系统层独占了三指纵向手势，
  `CGEventTap` 只能收到 type=29 且位移恒为 0，无法判定方向
- 识别到手势后，按你的配置注入按键事件（如 `⌘C` / `⌘V` / `⌘⌫`，需辅助功能授权）
  或启动 App / 调节音量 / 触发系统动作
- 内置防误触：三根手指必须同时移动、方向一致，避免两指滚动+一指悬停误触发

## 安装

```bash
cd ThreeSwipeCopy
bash install.sh
```

脚本会：

1. 用 SwiftPM 编译（仅需 Xcode Command Line Tools，不需要完整 Xcode）
2. 组装 `ThreeSwipeCopy.app` 并用固定证书签名
3. 复制到 `/Applications`
4. 启动应用

## ⚠️ 必须先改触控板设置（关键！）

系统默认把三指上滑/下滑分配给「调度中心」和「App 切换」，
会让三指手势被系统抢走。请打开 **系统设置 > 触控板 > 更多手势**：

- **调度中心（Mission Control）= 三指上滑** → 改成「四指上滑」或「关闭」
- **App 切换（App Exposé）= 三指下滑** → 改成「四指下滑」或「关闭」
- 想用**三指左右滑**（绑定动作）时，还要关闭「在全屏 App 之间轻扫」：
  **系统设置 > 桌面与程序坞 / 触控板 > 更多手势** 中把「在全屏 App 之间轻扫」改成四指或关闭

改完后三指手势就完全归本工具使用。

## 首次授权

首次运行时，请到 **系统设置 > 隐私与安全性 > 辅助功能**，打开「三指复制粘贴」的开关。
这是 macOS 对「注入按键」的强制要求（读取触点是私有多点触控 API，不需要授权）。

菜单栏会出现手势图标：

| 菜单项 | 说明 |
| --- | --- |
| 已启用 / 已暂停 | 开关全部手势功能 |
| 手势设置（13 个子菜单） | 每个手势可自定义绑定动作，见下 |
| 恢复默认动作 | 一键恢复出厂绑定 |
| 辅助功能已授权 | 点击跳转系统设置授权 |
| 开机自启动：已关闭 | 点击开启/关闭开机自启动（应用需位于 /Applications） |
| 退出 | 退出应用 |

## 自定义手势动作

菜单栏 → **手势设置**，每个手势（三指 4 个方向 + 两指 3 个 + 四指 5 个 + 按住+点按，
共 13 个）都有一个子菜单，可绑定：

**常用快捷键**（注入系统按键，需辅助功能授权）
复制 ⌘C · 粘贴 ⌘V · 剪切 ⌘X · 撤销 ⌘Z · 重做 ⌘⇧Z · 全选 ⌘A · 保存 ⌘S · 查找 ⌘F ·
删除到废纸篓 ⌘⌫ · 聚焦搜索 ⌘Space · 关闭窗口 ⌘W · 隐藏当前 App ⌘H · 最小化 ⌘M ·
切换 App ⌘Tab · 全屏 ⌃⌘F

**打开 App**（按 Bundle ID 启动）
访达 · Safari · Chrome · 终端 · 备忘录 · 邮件 · 信息 · 音乐 · 计算器 · 系统设置

**打开任意 App（自定义）**
「打开 App」分组末尾有 **选择其他 App…**：弹窗选择你自己喜欢的任意 App（例如微信、
VS Code、iTerm 等），手势就会变成打开它。已设置后会显示「打开 xxx」并打勾，
也可以随时 **清除自定义 App**。每个手势可以绑定不同的 App。

**媒体与音量**
播放 / 暂停 · 下一首 · 上一首 · 音量 + · 音量 - · 静音 / 取消静音

**系统控制**
调度中心 · 启动台 · 显示桌面 · 锁定屏幕 · 显示屏休眠 · 区域截屏（⌘⇧4）

> 媒体控制走 MediaRemote 私有框架（BetterTouchTool 同款），音量走公开 AppleScript API。

## 使用

**复制 / 粘贴（默认）**

1. 选中文字（或用鼠标/触控板选中文件）
2. **三指上滑** → 复制
3. 到目标位置 → **三指下滑** → 粘贴

**删除文件到废纸篓（默认四指手势）**

1. 在访达（Finder）中先选中一个文件
2. **食指、中指、无名指**三根手指轻轻按住触控板，保持不动
3. **小指轻点一下**（另外三根手指不要松开）
4. 文件被移到废纸篓（等同于 ⌘⌫，误删可到废纸篓恢复）

**两指 / 四指手势（可选，默认关闭）**

1. 打开 菜单栏 → 手势设置 → 给某个两指/四指手势勾选动作（例如「两指左滑 = 撤销」）
2. 按对应手势即可触发
3. 这些手势默认是「无动作」，因为：
   - **两指**与系统滚动 / 两指点按天然冲突，因此只认「快速轻点」和「落下 0.4s 内的横向甩动」
   - **四指滑动**默认被系统用于「调度中心（上滑）/ 显示桌面（下滑）/ 全屏 App 切换（左右）」，
     想绑定四指滑动需先到 系统设置 → 触控板 → 更多手势 里把对应系统手势关闭

## 开机自启动

安装到 `/Applications` 后，在菜单栏图标里点「开机自启动：已关闭」即可注册为登录项。
可以在 **系统设置 > 通用 > 登录项** 中查看和关闭。

## 常见问题

**某个手势想换成别的动作？**
点菜单栏图标 → **手势设置** → 选对应手势 → 勾选想要的动作，立即生效，无需重启。
改乱了就点「恢复默认动作」。

**某个手势想打开预设列表之外的 App？**
手势设置 → 该手势 → 「打开 App」分组 → **选择其他 App…**，在弹窗里选任意 `.app` 即可
（例如 /Applications/微信.app）。设置后菜单里会显示「打开 微信」，随时可清除。

**左右滑没反应？**
三指左右滑默认被系统用于「在全屏 App 之间轻扫」，请先在
**系统设置 > 触控板 > 更多手势** 里把它改成四指或关闭。

**两指 / 四指手势没反应？**
新加的「两指轻点 / 两指左右滑 / 四指滑动 / 四指轻点」默认是「无动作」，
需要先到 菜单栏 → 手势设置 → 对应手势 里勾选一个动作。
其中四指上/下/左/右滑会被系统默认手势抢走，需先到
**系统设置 > 触控板 > 更多手势** 关闭对应的系统手势（调度中心 / 显示桌面 / 全屏切换）。

**删除手势没反应 / 太灵敏 / 不灵敏？**
在菜单里确认「三指按住+小指点按」绑定的是「删除到废纸篓」。
若手感不对，可调整 `Sources/ThreeSwipeCopy/MultitouchMonitor.swift` 里的
`tapWindow`（第四指点按判定窗口）、`minPerFingerMove`（其余三指静止阈值）、
`matchTolerance`（位置匹配容差），然后重新 `bash install.sh`。

**没有反应？**
1. 确认已按上面说明把「调度中心 / App 切换」从三指手势改成四指或关闭
2. 确认已在辅助功能中授权
3. 确认菜单栏图标显示「已启用」
4. 看日志：`tail -f ~/Library/Logs/ThreeSwipeCopy.log`，应能看到 `[mt] 三指上滑/下滑 已确认`

**开机自启动点不了 / 报错？**
确认应用在 `/Applications` 下（不是从 dist 目录直接运行的）。

## 卸载

```bash
rm -rf /Applications/ThreeSwipeCopy.app
```

然后在 系统设置 > 隐私与安全性 > 辅助功能 里移除授权，在 登录项 里移除即可。
