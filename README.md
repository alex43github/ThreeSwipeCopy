## 🚀 为什么用它

- 🖐 **零学习成本**：三指上滑复制、三指下滑粘贴，选完文字直接甩手，肌肉记忆当天形成
- ⚡️ **极速轻量**：常驻菜单栏，内存占用极小，只为高频动作而生，不做花哨界面
- 🔒 **完全本地**：不联网、不上传任何数据，你的文字、文件、操作永远留在本机
- 🆓 **开源免费**：MIT 协议，代码完全开放，想改就改，想分叉就分叉
- 💡 **比 BetterTouchTool 更克制**：不需要复杂配置，装上就能用，默认动作开箱即用

## ✨ 功能亮点

| 手势 | 默认动作 | 说明 |
| --- | --- | --- |
| 👆 三指上滑 | 复制（⌘C） | 选中文字/文件后上滑即复制 |
| 👇 三指下滑 | 粘贴（⌘V） | 上滑复制后下滑即粘贴 |
| ↙️ 三指左/右滑 | 无（可绑定） | 可绑撤销、切换 Tab 等 |
| 🤏 三指按住 + 小指点按 | 删除到废纸篓（⌘⌫） | 选中文件后按住三指、小指点一下即删除，误删可恢复 |
| 👇 两指轻点 / 两指左滑 / 两指右滑 | 无（可绑定） | 快速甩动识别，不抢系统滚动 |
| 🖐 四指上/下/左/右滑 | 无（可绑定） | 需在系统设置中关闭对应系统手势 |
| 🖐 四指轻点 | 无（可绑定） | 四指同时落下抬起 |

> 共 **13 个手势**，每一个都可以在菜单栏里自定义绑定为：快捷键、打开 App、媒体控制、音量调节或系统动作。

## 🎯 快速开始（3 步）

### 1️⃣ 安装

```bash
git clone https://github.com/alex43github/ThreeSwipeCopy.git
cd ThreeSwipeCopy
bash install.sh
```

脚本会自动编译（仅需 Xcode Command Line Tools，无需完整 Xcode）、签名并安装到 `/Applications`，然后启动应用。

### 2️⃣ 授权辅助功能

首次运行后打开 **系统设置 → 隐私与安全性 → 辅助功能**，勾选「ThreeSwipeCopy」。
这是 macOS 对注入按键（模拟 ⌘C/⌘V）的强制要求。

### 3️⃣ 修改触控板设置（关键！）

打开 **系统设置 → 触控板 → 更多手势**：

- **调度中心（三指上滑）** → 改为「四指上滑」或「关闭」
- **App 切换（三指下滑）** → 改为「四指下滑」或「关闭」

> 想用**三指左/右滑**时，还需把「在全屏 App 之间轻扫」改为四指或关闭。
> 想用**四指滑动**时，把「调度中心」「显示桌面」「全屏切换」对应方向改为其他或关闭。

改完后三指手势就完全归本工具使用，即装即用 🎉

## 🎮 自定义手势动作

菜单栏图标 → **手势设置** → 每个手势都有子菜单，可绑定：

- **常用快捷键**：复制 / 粘贴 / 剪切 / 撤销 / 重做 / 全选 / 保存 / 查找 / 删除到废纸篓 / 聚焦搜索 / 关闭窗口 / 隐藏当前 App / 最小化 / 切换 App / 全屏
- **打开 App**：访达 / Safari / Chrome / 终端 / 备忘录 / 邮件 / 信息 / 音乐 / 计算器 / 系统设置
- **打开任意 App**：`选择其他 App…` 可指定你自己的任意应用（微信、VS Code、iTerm…），每个手势可绑定不同 App
- **媒体与音量**：播放/暂停 / 下一首 / 上一首 / 音量+ / 音量- / 静音
- **系统控制**：调度中心 / 启动台 / 显示桌面 / 锁定屏幕 / 显示屏休眠 / 区域截屏

## ⚙️ 工作原理

- 使用 Apple 私有框架 **MultitouchSupport**（BetterTouchTool / Jitouch 同款底层方案）直接读取触控板原始触点
- 每个手势都有独立的防误触状态机：位移阈值、时间窗口、冷却时间，**三指必须同向移动**才触发，避免误操作
- 为什么不走 `CGEventTap`：macOS 系统层独占三指纵向手势，事件流里位移恒为 0，无法判定方向
- 识别后注入按键（`⌘C` / `⌘V` / `⌘⌫`，需辅助功能授权）或启动 App / 调音量 / 触发系统动作

## ❓ 常见问题

**Q：手势没反应？**
A：先确认三件事：① 菜单栏图标显示「已启用」；② 辅助功能已授权；③ 系统三指手势已按上文改掉。

**Q：两指手势怎么有时候不灵？**
A：两指是系统滚动/缩放的保留区，本工具只识别「快速横向甩动」和「轻点」，请用干脆利落的动作。

**Q：会和 BetterTouchTool 冲突吗？**
A：会。两个工具都会抢占触控板手势，建议只运行一个。

**Q：误删了文件怎么办？**
A：删除只是移到废纸篓（等同 ⌘⌫），打开废纸篓即可恢复。
